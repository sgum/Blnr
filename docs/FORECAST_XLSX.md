# Формат файла прогноза

Вкладка «Загрузка прогнозов» и `R/forecast.R` читают **модельный воркбук**
(такой делается для каждого нового портфеля), а не таблицу «дата × тикер».

## Структура

- Лист **`Q_mean_var`** (если его нет — берётся первый лист).
- На листе есть блок с шапкой в **столбце 1 = `mean`**:

  ```
  mean | ix | .qM0 | .qM1 | .qM2 | ...
  Apple| 0  | ...  | ...  | ...
  Nvidia| 1 | ...
  ...            (инструменты человекочитаемыми именами)
  Nasdaq| 25
  <пусто/var>    ← конец блока mean (дальше идёт блок дисперсий var)
  ```

- **Строки** — инструменты (`Goldman Sachs`, `Nvidia`, `Google`, `AMD`,
  `General Electric`, …). Сопоставляются с тикерами `GS/GE/AMD/GOOG/NVDA`
  по `FORECAST_TICKER_ALIASES` (совпадение по целому слову).
- **Столбцы** `.qM0, .qM1, …` — шаги прогноза (горизонты).
- **Значения** — **уже накопленный** относительный прогноз роста бумаги на
  горизонт k, в долях (`0.012 = +1.2%`). Их берут напрямую, без
  перемножения по шагам.

## Шаг → дата

Календарных дат в файле нет. Шаг `k` раскладывается на **торговые дни
(пн–пт)** от `FORECAST_BASELINE_DATE` (`global.R`, по умолчанию 11.09.2026):
`.qM0` = базовая дата, `.qM1` = следующий торговый день и т.д. Праздники не
учитываются — это приблизительная сетка (см. `forecast_step_dates()` в
`R/forecast.R`, там же можно уточнить). На вкладке «Портфель Exante»
прогноз берётся на текущую дату (ближайший предыдущий доступный шаг).

## Настройка

- При старте приложение пытается подхватить файл по пути
  `FORECAST_XLSX_PATH` (переменная окружения; по умолчанию —
  `~/Downloads/quotes 2026-09-13 2.xlsx`). Для нового портфеля задайте
  свой путь в `.Renviron` или загрузите файл вручную во вкладке.
- Чекбокс «Значения в файле — доли … умножить на 100» включён по умолчанию
  (для формата Q_mean_var значения всегда в долях). Снимите его, только если
  в конкретном файле значения уже в процентах.

## Если структура отличается

`parse_forecast_file()` в `R/forecast.R` — место, где правится разбор.
Он ищет строку-шапку `mean` в первом столбце и читает инструменты до
пустой строки или строки `var`. Ошибка разбора показывается всплывающим
уведомлением с текстом причины.
