# Формат файла прогноза

Вкладка «Загрузка прогнозов» и `R/forecast.R` ожидают xlsx со следующей
структурой:

- Первый столбец — дата торгового дня (Excel-дата или число-серийник —
  оба варианта распознаются).
- Остальные столбцы — по одному на бумагу: `GS`, `GE`, `AMD`, `GOOG`,
  `NVDA` (или человекочитаемые варианты — "Goldman Sachs", "Google" /
  "Alphabet", "Nvidia" и т.п., см. `FORECAST_TICKER_ALIASES` в
  `R/forecast.R`).
- Значения — прогнозный относительный рост бумаги от уровня, достигнутого
  к 11.09.2026 (`FORECAST_BASELINE_DATE` в `global.R`). Если в файле это
  доли (0.05 = 5%), а не проценты (5 = 5%) — отметьте чекбокс «значения в
  долях» при загрузке, тогда они домножаются на 100.

По умолчанию приложение при старте пытается само найти файл по пути
`FORECAST_XLSX_PATH` (переменная окружения; если не задана — используется
`~/Downloads/Portfolio (1).xlsx`). Если файл называется/лежит иначе —
задайте `FORECAST_XLSX_PATH` в `.Renviron`, либо просто загрузите файл
вручную через `fileInput` на вкладке «Загрузка прогнозов» (это всегда
работает, вне зависимости от пути по умолчанию).

Если структура вашего реального файла отличается (другие заголовки,
несколько листов с разным смыслом, строка-баннер над таблицей и т.п.) —
`parse_forecast_file()` в `R/forecast.R` это место, где нужно поправить
парсинг: он был написан без доступа к самому файлу (агент, который его
писал, работал в среде без доступа к вашему компьютеру), по вашему
словесному описанию структуры. Ошибка парсинга показывается всплывающим
уведомлением с текстом причины — это должно быстро подсказать, что
поправить.
